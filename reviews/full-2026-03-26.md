# KubeLLM Full Codebase Review -- 2026-03-26

## Executive Summary

Evidence-based verification against the repository confirms the preliminary RAG API risks: **unauthenticated HTTP surface**, **client-controlled path construction in `upload_md`**, and **dynamic SQL identifiers** derived from form input. Findings are calibrated for a **local dev / research** tool (auth and CORS downgraded to **Warning** per review gate); **path traversal** remains **Critical** when the API is reachable. Discovery added **SSRF-class URL fetch**, **unbounded uploads**, **shared `session_state` under concurrency**, **`rag_api` double round-trips**, **duplicate DB URL constants**, **programmatic `config_overrides` flexibility**, and a **transitive `pygments` advisory** from `pip-audit` (re-run after upgrades).

## Findings

### SEC-001 API secrets in workspace `.env`

- **Severity:** Critical
- **Category:** Security
- **File:** `.env` (gitignored), `runtime_config.py`, `debug_assistant_latest/utils.py`
- **Line(s):** `.gitignore` line 19; runtime checks for `OPENAI_API_KEY` in code paths that load chat/embedders
- **Confidence:** 0.9
- **Evidence:** `.env` is ignored by git (see `.gitignore:19`). Application expects provider keys via environment (e.g. OpenAI paths in `runtime_config.py` / `utils.py`). No key material recorded in this report.
- **Impact:** Credential theft, quota abuse, or history exposure if `.env` is synced, copied, or ever committed.
- **Recommendation:** Rotate if exposure is possible; `git log --all --full-history -- .env`; never commit `.env`; use per-machine or managed secrets off localhost.

### SEC-002 Path traversal in Markdown upload

- **Severity:** Critical
- **Category:** Security
- **File:** `api_server.py`
- **Line(s):** 169–172
- **Confidence:** 0.95
- **Evidence:**

```169:172:api_server.py
    path = Path("./test_knowledge/" + file.filename)
    try:
        with open(path, 'wb') as f:
            shutil.copyfileobj(file.file, f)
```

- **Impact:** Crafted `file.filename` with `../` can write outside `test_knowledge/` depending on path resolution.
- **Recommendation:** `Path("test_knowledge") / Path(file.filename).name` (or UUID prefix); reject `..` and absolute names.

### SEC-003 Unsafe dynamic SQL identifiers (table names)

- **Severity:** Warning
- **Category:** Security
- **File:** `api_server.py`, `api_server_support.py`, `debug_assistant_latest/pgVector.py`
- **Line(s):** `api_server_support.py` ~35–36; `api_server.py` ~213–222; `pgVector.py` ~31–78
- **Confidence:** 0.88
- **Evidence:** `embeddings_model` from `/initialize/` flows into `knowledge_table_name()` then `text(f'TRUNCATE TABLE "ai"."{table_name}" ...')`. Similar f-string SQL in `pgVector.py` for SELECT/TRUNCATE/DROP helpers.
- **Impact:** Identifier injection / broken quoting if model names are hostile; worst when API is network-exposed.
- **Recommendation:** Allowlist embedder names; validate with strict regex; use `quote_ident` (with a live connection) for dynamic identifiers.

### SEC-004 CORS wildcard with credentials

- **Severity:** Warning
- **Category:** Security
- **File:** `api_server.py`
- **Line(s):** 27–33
- **Confidence:** 0.9
- **Evidence:** `allow_origins=["*"]` and `allow_credentials=True`.
- **Impact:** Overly permissive CORS; misleading combo with credentials in browsers.
- **Recommendation:** Explicit `allow_origins`; disable credentials unless required.

### SEC-005 Exception and error responses leak internals

- **Severity:** Warning
- **Category:** Security
- **File:** `api_server.py`
- **Line(s):** 38–44; multiple `HTTPException(..., detail=f"... {exc}")` on routes
- **Confidence:** 0.92
- **Evidence:** Global handler returns `f"Unhandled server error: {exc}"` in JSON `detail`.
- **Impact:** Paths, DB errors, or provider messages visible to API clients.
- **Recommendation:** Generic `detail` for clients; `logger.exception` server-side only.

### SEC-006 No authentication on RAG HTTP API

- **Severity:** Warning
- **Category:** Security
- **File:** `api_server.py`
- **Line(s):** all routes; `GET /chat_history/` ~241–244
- **Confidence:** 0.95
- **Evidence:** No auth layer; chat history returned to any caller on the port.
- **Impact:** Model use, ingestion, truncation of vector tables, and chat exfiltration if the port is reachable.
- **Recommendation:** Document localhost-only binding; add API keys or reverse-proxy auth for shared networks.

### SEC-007 Server-side fetch of user URL (SSRF risk)

- **Severity:** Warning
- **Category:** Security
- **File:** `api_server_support.py`, `api_server.py`
- **Line(s):** `scrape_url_to_document` ~39–48; `/add_url/` ~139–161
- **Confidence:** 0.85
- **Evidence:** `requests.get(url, ...)` with no host/scheme restrictions; `/add_url/` passes client `url` into `load_knowledge_document` → `scrape_url_to_document`.
- **Impact:** Probing internal IPs (e.g. metadata services) when the server can reach them.
- **Recommendation:** Block private/link-local ranges; optional allowlist; cap size and redirects.

### SEC-008 Unbounded upload and ingest size

- **Severity:** Warning
- **Category:** Security
- **File:** `api_server.py`
- **Line(s):** `/upload_md/` 163–185; `/upload_pdf/` 187–202
- **Confidence:** 0.9
- **Evidence:** No max size on `UploadFile`; full-body read for PDF/MD.
- **Impact:** Disk or memory exhaustion; large PDF parse cost.
- **Recommendation:** Starlette/FastAPI body limits; streaming caps; rate limits.

### SEC-009 Shared global `session_state` under concurrent requests

- **Severity:** Warning
- **Category:** Security
- **File:** `api_server.py`
- **Line(s):** 35; mutations in `/initialize/`, `/ask/`, etc.
- **Confidence:** 0.8
- **Evidence:** Single module-level `SessionState()` updated by async handlers without locking.
- **Impact:** Cross-request interleaving of messages and assistant handles.
- **Recommendation:** Per-session state or locks; document single-user assumption.

### SEC-010 Hardcoded default database credentials in source

- **Severity:** Warning
- **Category:** Security
- **File:** `runtime_config.py`, `debug_assistant_latest/pgVector.py`
- **Line(s):** `runtime_config.py` ~14–15; `pgVector.py` ~8
- **Confidence:** 0.9
- **Evidence:** `postgresql+psycopg2://ai:ai@localhost:5532/ai` duplicated as literals.
- **Impact:** Acceptable for default local Docker; unsafe if reused on reachable hosts.
- **Recommendation:** Environment-driven URL for non-local deployments.

### PERF-001 Extra HTTP round-trip on every RAG client call

- **Severity:** Warning
- **Category:** Performance
- **File:** `debug_assistant_latest/rag_api.py`
- **Line(s):** 89–94
- **Confidence:** 0.95
- **Evidence:** `_ensure_server_compatible(base_url)` runs on every `_request` except `SERVER_INFO_PATH`.
- **Impact:** ~2x HTTP calls for `ask_question`, `add_url`, `clear_knowledge_base`, etc.
- **Recommendation:** Cache successful compatibility check per process (TTL or until mismatch).

## Test Coverage Gaps

- FastAPI: `upload_md`, `upload_pdf`, `add_url`, `clear_knowledge_base`, `initialize`, `chat_history`, global exception handler.
- SSRF / URL policy for `scrape_url_to_document` and `load_knowledge_document`.
- CORS behavior with credentials (contract or browser tests).
- Concurrent use of `session_state` if multi-client is ever a goal.
- RAG client: caching of `_ensure_server_compatible`.

## Recommendations Priority

1. **Immediate:** Confirm `.env` never entered git history; rotate if unsure; fix `upload_md` path handling; bind API to localhost unless auth is added.
2. **Short-term:** Identifier allowlisting; generic client errors; SSRF controls; upload limits; cache RAG compatibility in `rag_api.py`.
3. **Medium-term:** Split `runner.py`; single DB URL source; dependency locks + `pip-audit` in CI; expand tests per TEST-001.
